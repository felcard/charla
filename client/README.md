# Charla client

React front end for [Charla](../README.md). See the root README for what the app does, how it works and how to run it.

```sh
npm start        # dev server on :3000, talks to the local server on :8000
npm test         # unit tests
npm run build    # production build in build/, talks to the live server
```

`REACT_APP_SERVER_URL` sets the Socket.IO server; see `.env.example`.
